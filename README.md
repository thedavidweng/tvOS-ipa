# tvOS IPA

Decrypted Apple TV + Apple Arcade IPAs (with `NSApplicationRequiresArcade` removed), published as an installable source.

**Subscribe URL:** `https://thedavidweng.github.io/tvOS-ipa/apps.json`

## Where to download

GitHub Releases cap each file at **2 GiB**. This repo keeps using GitHub for every IPA that fits.

[SourceForge](https://sourceforge.net/projects/tvos-ipa/) is the **superset**:

- IPAs that already exist on GitHub can be mirrored there (code import is not enough — enable **Files → GitHub Integration**, or Admin → Import **Releases**). GitHub does not notify SourceForge when files are added to an *already published* release; edit that release’s notes, or publish a new release, if the first sync missed assets.
- IPAs **larger than 2 GiB cannot be stored on GitHub at all**. They are uploaded to SourceForge only.

Files: <https://sourceforge.net/projects/tvos-ipa/files/>  
Direct link pattern: `https://downloads.sourceforge.net/project/tvos-ipa/<FileName>.ipa?viasf=1`

## Upload to Release

To upload an IPA package to [GitHub Release](https://github.com/thedavidweng/tvOS-ipa/releases) (≤ 2 GiB) or [SourceForge Files](https://sourceforge.net/projects/tvos-ipa/files/), name it as per the example.

### Naming Requirements

- Start with the application name without any **spaces** and **punctuation**. For example, for **Air Twister**, please name it `AirTwister`.
- Then the application version number, separated by **underscores**. For example, `AirTwister_1.4.0`.
- For injected plugins, please write the plugin name and version number, separated by **underscores**. For example, for **微信助手**, please name it `MiYou_1.1.1`.
- If you do not know the name and version number of the injected plugin, but only know that it is a cracked version, please write `Pro`. If it is just decrypted, append nothing.
- The application name, version, and plugin info are all connected by **underscores**. No trailing tag of any kind is added in this repo.

### Some Examples

`Air Twister (decrypted): AirTwister_1.4.0.ipa`

## 下载位置

GitHub Release 单文件上限是 **2 GiB**。能放进 GitHub 的 IPA 继续放 GitHub。

[SourceForge](https://sourceforge.net/projects/tvos-ipa/) 是 **超集**：

- GitHub 上已有的 IPA 可以镜像过来（只同步代码不够，需要在 Files 里打开 **GitHub Integration**，或 Admin → Import **Releases**）。GitHub 不会在「已经发布的 Release 里后补文件」时通知 SourceForge；如果第一次没同步到，改一下该 Release 的说明，或再发一个新 Release。
- **超过 2 GiB 的 IPA 无法放上 GitHub**，只在 SourceForge。

文件列表：<https://sourceforge.net/projects/tvos-ipa/files/>  
直链格式：`https://downloads.sourceforge.net/project/tvos-ipa/<FileName>.ipa?viasf=1`

大于 2 GiB 的包见上面的表格。

## 上传到 Release

将 IPA 软件包上传到 [GitHub Release](https://github.com/thedavidweng/tvOS-ipa/releases)（≤ 2 GiB）或 [SourceForge Files](https://sourceforge.net/projects/tvos-ipa/files/) 即可，请按照示例命名。

### 命名要求

- 以应用程序名称开头，不含任何 **空格** 和 **标点符号**。例如，**Air Twister** 请命名为 `AirTwister`。
- 然后是应用版本号，用 **下划线** 分隔。例如，`AirTwister_1.4.0`。
- 对于注入的插件，请写明插件名称和版本号，并用 **下划线** 分隔。
- 如果不知道注入插件的名称和版本号，只知道是破解版，请写成 `Pro`。如果仅仅是砸壳，什么都不加。
- 应用程序名称、版本号和插件信息均由 **下划线** 连接。本仓库不在末尾加任何标记。

### 一些例子

`Air Twister（仅砸壳）：AirTwister_1.4.0.ipa`
